# okb-v2 项目心智模型（一页版）

> 用途：先建立整体图像，再按模块深挖。细节查询用《白板三图-答案卡》，模块自评用《项目全景-理解度导图》。
> 原则：这一页里不出现英文字段名——那是下一层的事。

## 一句话

**这是一座"考试工厂"：出题 → 考试 → 双轨阅卷 → 定级 → 统分。**
全厂只有一个验收标准：**每一个结论都必须能回答"凭据在哪"。**

## 一、五个角色（把仓库里的东西归成五类）

| 角色 | 是什么 | 仓库位置 |
|---|---|---|
| 题 | 一段多会话剧本 + 初始环境 + 出题人写的"正确答案声明" | 作者稿 / 正式卷 |
| 计划 | 把题编译成可执行的"检查清单"（每条要求+失败时归哪类） | 四层计划 |
| 考生 | 两个被测 Agent（OpenClaw / Hermes） | 引擎运行产物 |
| 录像 | 考试全过程证据：对话、记忆前后、文件前后、工具动作 | 证据库 raw/ |
| 判定 | 每条检查的结论 → 每题的结论 → 六个维度的指标 | 评分结果 / 报告 |

## 二、流水线（全局图）

```
作者稿 ──编译──> 卷 + 计划 ──考试──> 证据库 ──阅卷──> 判定 ──统分──> 六维指标/雷达
   │                │                  │            │
   └──质检 lint─────┴────验收门────────┴──判官纪律──┴──人审/A-A（可信层）
```

三个关键分界（面试讲这里就够了）：
1. **编译分界**：题是"人写的"，计划是"机器编译出来的"——所以有 40+ 条质检规则，拦坏题、坏判据；
2. **证据分界**：阅卷只认录像；录像看不到的东西，"没拍到"不等于"没发生"——所以有"弃权"哲学；
3. **判定分界**：两条阅卷线——规则线（搜正则，快而硬）和语义线（判官读切片，灵活但有主观性）。

## 三、三个"一生"（把流水线串起来的最小叙事）

1. **一道题的一生**：创作（剧本+环境+答案声明）→ 编译（检查清单+版本锁）→ 考生作答（清场、三次重复）→ 录像 → 逐检查判定 → 一个题目结论（通过/失败/弃权）。
2. **一条判定的一生**：看到一个现象（证据）→ 对照一条要求 → 三选一（达成/违背/说不清）→ 所有要求汇总成题目结论 → 失败时按"第一处违背"归类（五分类）。
3. **一个分数的一生**：题目结论 → 按维度数数（分子/分母）→ 剔除说不清的（并公示覆盖率）→ 出通过率 → 画雷达。

## 四、五条铁律（项目价值观，比机制更重要）

1. **版本锁死**：任何数字都能追到确切的卷/计划版本；换了版本就换一批数字，不混用。
2. **证据先验**：先问"证据可信吗"，再问"答对了吗"；证据不可信就弃权，不是判 0。
3. **宁可弃权，不可冤枉**：说不清 ≠ 做错；但弃权要从分母剔除并公示（否则分数虚高）。
4. **答案隔离**：判官看不到出题人写的答案（防开卷考试）；被测看不到判据（防应试）。
5. **失败保留**：失败批次不覆盖、不重试、换新编号——失败本身是证据。

## 六、故障模式（把这次审计的全部发现抽象成五类）

| 故障 | 抽象 | 你项目里的真实事件 |
|---|---|---|
| 判词反 | 出题人写的"扣分条件"被判官当成"加分条件"读 | 极性反判：17 题判死、2 题假通过（已修） |
| 录像盲 | 摄像头没拍到的区域被当成"没发生" | "采不到≠没记住"；记忆面可比性 |
| 归因混 | 一题里几件事（记忆/格式/质量）混在一个分数里 | 应用失败 vs 存储失败不可分 |
| 判官抖 | 同一录像两次判卷结论微动 | A/A 1.25% 翻转（已量化） |
| 无校准 | 全是机器判的，没人看过 | 人审=0 → 不给正式成绩 |

**五类故障对应五个防线**：判词 lint（防反）、采集自证+弃权哲学（防盲）、检查族分流（防混）、A/A/多轮（防抖）、人审 κ（防无校准）。这五条就是项目方法论的核心。

## 七、学习路径（缩放级别）

- **L0 一句话**（已会）：考试工厂，结论必须有凭据。
- **L1 流水线**（本页）：五个角色、三个分界、五条铁律。
- **L2 三个一生**（能口述）：题/判定/分数怎么流动。
- **L3 字段级**（按需深挖，用《白板三图-答案卡》查）：
  建议顺序 **引擎（考试）→ 判分层（阅卷）→ 校验层（门禁）→ 内容层（出题）→ 可信层**；
  每个模块只回答三个问题：**输入什么、输出什么、什么情况下拒绝干活**。
