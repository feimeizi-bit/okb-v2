## 4. 关键结论（会话沉淀，新会话沿用）

1. **okb-v2 现状**：92 题 = 存量修复 68 + 新著 24；计划 330 检查；断言库 629 槽；lint 0E/61W（W206/208/212=0、W207×9 豁免、W205×52 注记）；**真人标签=0**；待办链=冒烟→600采集(≈552)→判官→收尾。
2. **评测岗定位结论**：漏斗窄但通过率高；双非可破（内推+项目匹配）；实习转正是最优路径；**最大敌人不是初筛，是"讲不清项目"**。
3. **项目叙事**：Agent 基础设施——"让 Agent **可控**（SafeDesk）、**可测**（okb）"；okb 对 Agent 岗的价值="懂 Agent 怎么坏、怎么稳、怎么证明它变好了"。
4. **简历定位句**（评测版）：
   > "为 openKylin 生态构建长期记忆自动化评测 Benchmark：92 题六维题库 + 40+ 条数据 lint + 证据链评分（规则/判官四层）+ κ/盲审/预注册可信度闭环；完成真实双 Agent 全量跑批（64/64 零损失）。"
5. **lint 三原型**（可迁移积累）：矛盾类（E201/E118）· 可达性类（E202/E120/W206）· 区分力类（E203/W207）。
6. **共享八股 P0 清单**（已给未成卡）：Python 并发/GIL（2 天）→ 网络（1 天）→ OS（1 天）→ DB/Redis（1 天）→ Linux/Git（0.5 天）→ 系统设计概念（0.5 天）；全部要求挂到用户自己的代码上回答（项目锚定法）。
