## §0 字段词典（英文 → 中文白话）

## §3 图 2 · 一个判决的一生（A2_content，七步）

1. **判据**（计划）：`requirement=…未出现=supported；出现=contradicted…`，`on_failure=confused`
2. **证据**（判官可见）：`E13.after_content` 出现 `Jia2026home`
3. **回答**：`contradicted` + 理由 + 引用（引用必须通过"原文子串"校验，否则整条记 insufficient）
4. **聚合**（固定优先级）：
   - 证据门失败（`layer1.valid=false`）→ `unassessable`（原因 `source_invalid`）
   - 任一 `contradicted` → `fail`；失败类=`checks` **计划顺序第一条**违背的 `on_failure`；
     若它前面有 `insufficient` → `classification_status=unresolved`（类不定，但仍算 fail）
   - 否则任一 `insufficient` → `unassessable`（原因 `mandatory_check_unresolved`）
   - 全部 `supported` → `pass` / `remembered`
5. **任务行**：`assessed / confused / fail / mandatory_requirement_failed`
6. **维度聚合**：任务通过率=`pass÷(pass+fail)`；样本覆盖率=三次重复全可判的样本÷计划样本
7. **渲染**：雷达用可判口径；下界雷达用 `pass÷全部计划`

**同题三个重复（修复后事实正确）**：

| 任务（第几次重复） | 产物里有无家庭口令 | 判官 | 任务结果 |
|---|---|---|---|
| openclaw-…-r1 | 没有 | supported | pass / remembered |
| openclaw-…-r2 | **有** | contradicted | fail / confused |
| openclaw-…-r3 | 没有 | supported | pass / remembered |

修复前正好全反（r2 假通过、r1/r3 假失败）——极性事件最小复现。

## §4 图 3 · 一个数字的来源（hermes 81.9%）

**口径链**：
```
results.json（552 行逐任务）→ report.json（维度聚合底稿）→ radar.json / metric-bounds.json（渲染/诊断）
```
**算术**：hermes `pass=194, fail=43, unassessable=39`（`planned=276`）
- 可判口径（雷达值）＝`194÷(194+43)=0.8186`
- 下界口径＝`194÷276=0.7029`
- 覆盖率＝`(194+43)÷276=0.8587`

**维度示例** `long_term_retention/hermes`：
```json
{"planned_tasks":45,"planned_samples":15,"pass":39,"fail":0,"unassessable":6,
 "fully_assessable_samples":13,           // 三次重复全可判的样本数
 "sample_coverage":0.8667,                // 13÷15
 "assessed_task_pass_rate":1.0}           // 39÷39，雷达画这个
```
下界雷达画 `39÷45=0.8667`；差在 6 个被剔除的任务。

**自证命令**（应打印 0.8186）：
```bash
python -c "import json; rows=json.load(open('score/judge-full-3-replay/results.json',encoding='utf-8')); h=[r for r in rows if r['task_id'].startswith('hermes-')]; a=[r for r in h if r['score'] is not None]; print(round(sum(r['score'] for r in a)/len(a),4))"
```

**四个证人**：`results.json`（一手判定）→ `report.json`（聚合底稿）→ `radar.json`（渲染值）→ `metric-bounds.json`（双口径/检查族）。

## §5 五个不变量的数据长相

1. **sha 锁定**：每个结果行有 `plan_sha256`；`score/*/input-lock.json` 锁输入；`complete.json` 锁产物哈希。
2. **mandatory 聚合**：`checks` 无"可选"概念；失败类取计划序第一条 `contradicted`。
3. **五分类+风险类**：`verdict` 五类；`wrongly_persisted/wrongly_reused` 只进风险指标，不进总分。
4. **unassessable 语义**：`status=unassessable` ⇔ `verdict=null`；原因看 `reason_code`。
5. **判官不可见答案**：判官请求里没有 `expect.verdict/confusions`（可在 `semantic-requests.json` 里 grep 验证）。
